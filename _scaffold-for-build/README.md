# اسکلت پیکربندی (فقط مرجع)

ZIP ورودی فاقد package.json / tsconfig.json / postcss.config.mjs / next.config بود و
شبکهٔ محیط من اجازهٔ نصب پکیج‌ها را نداد، پس `next build` اجرا نشد.
اگر این فایل‌ها را در پروژهٔ خودت داری، از همان‌ها استفاده کن و این پوشه را نادیده بگیر.
اگر نداری، این سه فایل را به ریشهٔ پروژه کپی کن (نسخه‌ها تخمینی و آزمایش‌نشده‌اند).
